> 创建独特的、生产级前端 UI，并迭代优化。一个 Skill，5 种模式，15 种增强子模式。

## What it does / 功能介绍

A comprehensive frontend design quality skill that merges 20+ design operations into one unified workflow:

一个全面的前端设计质量 Skill，将 20+ 种设计操作合并为统一工作流：

1. **Create / 创建** — Build UIs with bold aesthetic direction, distinctive typography, OKLCH color system, orchestrated motion / 以大胆美学方向构建 UI，独特排版、OKLCH 色彩系统、编排动效
2. **Audit / 审计** — Score 5 dimensions (hierarchy, consistency, a11y, responsiveness, performance) / 从 5 个维度评分（层次、一致性、无障碍、响应式、性能）
3. **Enhance / 增强** — 15 sub-modes: animate, colorize, typeset, arrange, adapt, bolder, quieter, delight, onboard, clarify, harden, optimize, extract, normalize, overdrive / 15 种子模式
4. **Polish / 打磨** — Pre-ship checklist covering alignment, spacing, states, dark mode, loading / 发布前清单
5. **Distill / 精简** — Remove decorative-only elements, reduce to minimum effective set / 精简到最小有效集合
6. **Critique / 评审** — Nielsen's 10 heuristics, persona walk, cognitive load analysis / 尼尔森十大可用性原则、用户角色走查、认知负荷分析

## Trigger / 触发方式

- Ask to build, design, or create any frontend UI / 要求构建、设计或创建任何前端 UI
- Ask to review, audit, or improve existing frontend code / 要求审查、审计或改进现有前端代码
- Or mention / 或提及：`前端设计` / `UI 优化` / `make it look better` / `polish this` / `responsive design` / `accessibility` / `animation` / `typography` / `color palette`

## Modes / 模式

| User Intent / 用户意图 | Mode / 模式 |
|---|---|
| build / create / make / design | **CREATE** |
| audit / check / review / score | **AUDIT** |
| animate / color / font / layout / responsive / ... | **ENHANCE** (15 sub-modes) |
| polish / final / ship / cleanup | **POLISH** |
| simplify / strip / minimal | **DISTILL** |
| critique / UX / heuristic | **CRITIQUE** |

## Key Design Principles / 核心设计原则

- **Banned fonts / 禁用字体**: Inter, Roboto, Arial, Poppins, Montserrat, Open Sans
- **Banned patterns / 禁用模式**: Purple-blue gradient hero, 3 identical cards, pure grays, uniform padding
- **Required / 必须包含**: `prefers-reduced-motion`, `prefers-color-scheme`, WCAG AA contrast, fluid `clamp()` sizing, CSS custom properties
- **Color system / 色彩系统**: OKLCH-based palette with tinted neutrals and dark mode

## Output / 输出

- Production-ready HTML/CSS/React code following all design rules / 遵循所有设计规则的生产就绪代码
- Structured audit reports with severity-prioritized action plans / 结构化审计报告，按严重程度排序
- Accessible, responsive, performant UIs that avoid generic AI aesthetics / 无障碍、响应式、高性能的 UI，避免 AI 生成感
