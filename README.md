# AI Skills Collection

A curated collection of Claude Code skills (.skill files) for enhancing AI-assisted workflows.

Claude Code Skills 合集 —— 一组可复用的 .skill 文件，用于增强 AI 辅助工作流。

## What are Skills? / 什么是 Skills？

Skills are reusable prompt packages for [Claude Code](https://claude.ai/claude-code) that give Claude specialized capabilities — from analyzing resumes to generating reports. Each `.skill` file can be installed into Claude Code and triggered via slash commands or natural language.

Skills 是 [Claude Code](https://claude.ai/claude-code) 的可复用提示词包，赋予 Claude 特定领域的专业能力。每个 `.skill` 文件可以安装到 Claude Code 中，通过斜杠命令或自然语言触发。
